# Acharya AI — manual test releases

Latest local Android candidate: `Acharya-AI-1.0.12-rag-arm64.apk` (version code 13, package `com.acharya.app`). APKs and signing material are intentionally excluded from Git.

Select the book/chapter, select the original question-paper photo or PDF, and tap Verify Paper. Paper review sends original bytes directly to OpenAI without requiring reference publication. Inspect the curriculum-fit estimate, then use Discuss this paper in Chat to ask about the findings or reopen the circular summary.

The app reuses the existing Neon curriculum library; no book re-embedding is needed. Provider credentials remain server-only. See [1.0.12 verification](Acharya-AI-1.0.12-verification.md) for checks and limitations. Physical-device testing of this candidate remains manual.
